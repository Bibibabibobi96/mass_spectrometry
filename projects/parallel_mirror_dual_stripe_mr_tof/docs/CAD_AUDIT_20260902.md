### Assembly pose recovery

The working-copy `离子箔装配组件.SLDASM` then opened silently and read-only with
58 components, error code 0, warning code 0. The project script
`analysis/solidworks_ion_foil_assembly_audit.py` saved the eleven relevant
Ion-Foil, grounded, and prism instances, their local boxes, and their complete
SolidWorks rigid-transform arrays to
`ion_foil_assembly_global_pose.json` beside the local-curve evidence.

The explicitly versioned candidate mapping is now
`config/cad_to_theory_frame.json`, verified by
`analysis/cad_pose_contract.py`: CAD X maps to project slow-drift `y`, CAD Z
maps to project reflection `z`, and the CAD mechanical midplane `Y=30 mm` maps
to project `x=0`. It is a full rigid point transform, so it is also inverted
and unit-tested rather than being repeated as ad-hoc axis swaps in SIMION Lua.

For the Candidate's fixed four-electrode/two-bias contract, the mirrored Ion
Foil 1 pair is assigned to Stripe set 1 (`11`, `12`) and the mirrored Ion Foil
3 pair to Stripe set 2 (`13`, `14`). The centred Ion Foil 2 is retained as the
central-ground candidate (`15`), with the two `grounded` components recorded as
additional grounded hardware. This remains a Candidate electrical assignment;
the source archive does not provide a verified wiring/netlist.

### Physical Stripe edge evidence and theory conflict

`analysis/solidworks_stripe_profile_audit.py` additionally reads the long
body-edge B-splines, after both the assembly and CAD-to-theory transforms. Its
run-local result `stripe_long_bspline_profiles.json` contains the actual
project-frame (z(y)) control curves for every physical Stripe. The long axis
is approximately 390 mm in project `y`, as expected for the slow-drift
coordinate.

That direct evidence also exposes a topology conflict: on both sides of
`z=0`, the raw Foil 1 and Foil 3 envelopes overlap in `z`. They cannot be
represented as two independent constant-voltage, overlapping conductors while
also using the non-overlap linear dual-Stripe theory. The full Candidate must
therefore retain the measured profile curves but move their axial zones into a
serial, positive-gap layout around the central grounded corridor. This is a
theory-priority resolved geometry change, not a claim that the archived CAD is
already electrically compatible with the new parallel-mirror design.

The corresponding resolved Candidate GEM now represents all four Stripe
profiles as `extrude_yz` project-frame solids: the Foil 1 profile is translated
outward by 35 mm, leaving a positive 2 mm minimum axial separation from the
Foil 3 profile. The CAD-positioned prism envelopes are represented by paired
triangles with their measured `x`, `y`, and `z` extents. SIMION 2020 compiled
this 25-electrode version at `(8, 8, 0.4) mm/GU`; each ideal grid occupied one
raw `z` row. This proves geometry-format closure only, not a closed ion flight.
