# 开放路径平行镜双条带 MR-TOF 项目状态

## 项目定位

本项目面向开放路径多次往返飞行拓扑：离子在一组名义平行的伸长等时镜之间沿反射轴快速往返，同时
沿漂移轴缓慢展开、转折并返回注入端。两套独立偏压、独立形状的漂移条带电极组共同提供两个能量响应
基，用于分别约束空间返回和时间平台；它们是同一分析器的耦合部件，不是两个profile。

当前只建立这条平行镜双条带硬件设计线。原 Astral 的“收敛镜 + 单形状 Stripe/Ion Foil 响应”保留为
理论对照和解析回归，不启动单 Stripe 项目，也不作为本项目mode。长期目标是建立从理论、机器可读
baseline、参数化几何、独立求解器验证到 SolidWorks CAD 和性能优化的受控闭环。本项目与单次反射
正交加速TOF质量分析器平级；只有经两个项目实际复用和验证的TOF方法才可提升到`common/`。

棱镜电压与加速/镜能量采用不同物理量。离子加速前保留漂移方向 `5 eV`，正交加速器在快速反射方向
增加约 `4 keV`，后者是离子轴向能量尺度而不是 P1/P2 电压。硬边界式
$v=w_0\cos(\alpha+\beta)\sin(\beta-\alpha)$ 给出百伏量级种子；约 `4 kV` 的棱镜偏压会与离子能量同阶，
不在当前小角度连续透射支路上。旧 `sqrt(5*4000)=141.421... V` 只保留为量级参考，不能充当完整
双棱镜解。

真实制造路径已经由有限三维事件确定为：加速器出口 → P1(ID 16) 折射 → **负镜预反射** →
P2(ID 17) 折射 → 正侧物理 Stripe 带区 → 首个正镜转折。两个棱镜都在主漂移开始前，且棱镜是通过/
折射事件，不是 `v_z` 反号事件。原 `source → P1 → P2 → Stripe` 直线硬边界构造忽略了两棱镜之间的
分布场镜反射，现只保留为明确声明“中间无镜”的通用组件回归；本制造模型必须使用真实三维轨迹射击。

慢漂移相位原点取 P2 后首个正侧镜转折：$y=0$、$v_z=0$、$v_y>0$。这里的正侧由 P2 出口沿
项目 `+z` 的实际路径自然决定，不是任意选择；完整漂移结束时应回到同一正侧镜转折相位，$y=0$ 且
$v_y<0$。Stripe 开启后的实际 $z_t$ 由三维轨迹定位，裸镜转折坐标只作诊断。P1/P2 的两个独立残差是
该正镜转折的 $y$ 以及相容 Mirror--Stripe 解给出的慢动能；$v_z=0$ 是事件定义，$x=0$ 是对称诊断，
均不重复计作可调约束。

旧受管审计
`20260908_173000__analysis__python__two-prism-definition-authority`记录的是被上述澄清取代的
“P2 出口即 $y=0$ Stripe 入口”解释，只保留为历史根因证据，不能再作为活动 P1/P2 定义性结论。新的
合同审计接受事件定位的正镜转折规则而不接受固定 `target_project_z_mm`；下一份受管三维 Jacobian 收据形成前，
P1/P2 电压和完整中心源仍保持未发布。

解析入口角由两个正交能量分量确定为
$\vartheta_0=\arctan\sqrt{w_y/w_z}$，并须与项目理论式
$\vartheta_0=\arcsin[\kappa(1)L/(KW)]$ 做目标 K 一致性检查。公开 Astral 的
`1.784°/335 mm/641 mm` 仅用于函数回归，不能写入本 Candidate 工作点。这里的
$L=340\,\mathrm{mm}$ 与 `5/4000 eV` 分量是当前制造设计/源合同输入，$\kappa(1)$ 由书面系数积分，
而 $W$ 先由
**独立的镜理论**确定：固定镜几何上的 Berdnikov L0/L1 仅用镜自身的三点等时、转折、Poincare 稳定与
$\gamma$ 条件求 B--E，并发布镜周期/W receipt。系统层再用 K 关系筛选镜理论合格族，不能让 Stripe
电压反向充当镜方程。Stripe 的 $S_0$ 基线可改变完整分析器的飞行周期与
时间响应，但不反向参与镜电压求解，也不以 $K$ 或入口角回代镜理论。

因此当前加工镜的理论链是“镜几何 $\to$ 镜 B--E 与 W receipt $\to$ Stripe/P1/P2”。镜电压求解完成后，
该 W receipt 是 Stripe 理论的冻结输入而非一个额外拟合坐标；不得把它与另一个外部 W 一起拟合。
未来新硬件设计可把 W 作为镜设计指标并联立镜几何和镜电压，但仍不应由 Stripe 电压反求已独立定义的
镜电压。

2026-09-08 的粒子源合同已将三个诊断截面和完整整机中心源分离：`mirror_internal_diagnostic`仅允许
从分析器内部直接释放粒子以隔离mirror/Stripe，`accelerator_focus_diagnostic`仅检查二区静态第一时间
焦点，`first_prism_entry_diagnostic`仅检查P1接口。`full_mrtof_center`仍须闭合含 Stripe 局部周期的
累计快相位、同一正镜转折相位返回以及 P1/P2 有限三维输运后才能发布；裸镜归一化
$T_D(\vartheta_0)/T_0=K$ 只提供解析初值。
SIMION完整中心飞行入口只接受这个具名完整源；旧镜内4-keV粒子不得替代它来发布整机传输、探测TOF、
分辨率或Candidate性能。

联合计算在发布任何数值前还必须报告**定义性判据**：列出物理未知量、具名残差，并用合同给定的参数/
残差尺度对实际 Jacobian 做 SVD。报告独立秩、零空间维数、冗余约束数、条件数，以及缩放残差在
Jacobian 左零空间中的不可消除分量。秩低于未知量数是欠定义；方阵满秩才是 `square_exact`；约束多于
未知量但满列秩且不可消除分量在容差内是 `overdetermined_consistent`；否则是
`locally_incompatible`。仅比较“方程条数 = 参数条数”或把满列秩超定系统称为“恰定”都不构成
发布证据，冗余/相关约束和当前 CAD 系数与理论关系之间的矛盾必须显式暴露。

时间平台现采用用户指定的四个转折归一化节点 $\eta_D=[0.90,0.95,1.05,1.10]$，并以每点
$\mathrm d\tau_g/\mathrm d\eta_D=0$ 为目标。它们在原理论所述 $1\pm0.1$ 范围内且关于标称点
对称；原文未公开四节点位置，因此该选择以用户规定为权威，绝不称为论文原始节点。论文未公开的节点、
权重、容差、窗口和类似细节同样须由用户规定并冻结到项目合同，不得由实现自行补默认值。每次联合求解仍须验证这些节点映射的物理
$y$ 位于两条冻结 Stripe 有效 B-spline 区间内，并把四个残差一起计入 Jacobian 秩与相容性检查。

镜 L0 的 `reduced_period` 仍定义为完整两镜轴向解析参考 $R\,[\mathrm{mm}/\sqrt{\mathrm V}]$，其关系
$W=R\sqrt{E/q}$ 是**不含 Stripe 作用量的独立镜理论**输出；在镜自身恰定并通过 L0/L1 后，它可作为
镜周期/W receipt，但不是完整分析器或分辨率 Candidate receipt。下游完整分析器时间响应须另行加入双
Stripe 基线作用量；在 Stripe 的 $\psi/g$、端点正则化空间返回与目标 $K$ 以及 P1/P2 输运闭合前，
入口相空间继续保持未解。

理论链分为三个有向问题。第一题仅以固定镜几何和镜的能量条件求 Mirror B--E；镜周期/W 是其输出 receipt。
第二题首先读取用户确认的两条制造曲线：它们正是以 $L=340\,\mathrm{mm}$ 生成的原理论高次
$\psi_s$ 与线性 $\psi_m$ 两个几何基函数。去除入口基线并投影其系数后，两个几何尺度通过有限偏压
硬边界作用量式解析反演成名义 $(v_1,v_2)$，不再用广域随机搜索猜初值；两电压仍是随后三维场校正的
可调坐标。解析点继续独立报告 $K$、$\kappa'(1)$ 和四节点时间平台，不能用调压掩盖定义冲突。
同一试点仍报告包含 Stripe 基线作用量的三个完整分析器局部能量斜率，但它们属于后续 TE1/TE2 全局校准，
不作为决定 $(v_1,v_2)$ 的额外等式。`5 eV` 是加速前保留下来的漂移方向名义能量；加速器增加的
`4000 eV` 是镜和 Stripe 轴向作用量所用的快反射能量，总动能为 `4005 eV`。因此入射角由该正交
分解确定；K 关系对当前镜 receipt 构成额外系统一致性检验，而不是又一个可由 Stripe 电压吸收的条件。
第三题才以冻结源状态、第二题导出的 Stripe 入口状态及 CAD/坐标变换为输入，求路径顺序 P1(ID 16)、
P2(ID 17) 的两个电压。棱镜电压不得混入第二题来掩盖固定 Stripe 曲线的不相容。Stripe 入口的位置、
方向、名义转折点、$\kappa(1)$ 和 $\theta_0$ 都是导出量；当前 $L$ 则是制造设计输入，绝不能在本硬件
线上倒置成拟合坐标。三维 P1/P2
输运必须将源射线送到理论要求的 Stripe 入口点和方向。三个问题分别使用尺度化 Jacobian SVD 与左零空间
残差判定定义性和相容性；欠定或不相容时只报告诊断，绝不以扫描、默认电压或固定入口条件伪造解。

独立镜理论的轴向目标不是两个“端点周期等于中心周期”残差，而是**仅有**三个能量点
$s_T(3900\,\mathrm V),s_T(4000\,\mathrm V),s_T(4100\,\mathrm V)$ 的局部归一化周期斜率都为零；
它们是四个 B--E 电压的三条 L0 等式，故固定几何的 L0 正确产物是一个解族，而不是唯一电压向量。
此前实现只编码两个周期差，是实现遗漏；现已改为在每个能量节点局部差分计算三条 $s_T$，且数值
微分步长及三条斜率的最大绝对容差均必须显式给定并做收敛检查；优化器的数值终止本身不是物理解。
横向 $\gamma=90^\circ$、稳定性和 $\overline T_{xx}$ 是 L1 的
镜内筛查/代表解选择条件，不能静默充当第四条轴向方程。外端 E 的反射条件、$\pm10\,\mathrm{kV}$ 包络、
全能量窗 Poincare 稳定和安全转折分支是该族的可行性条件。L1 对每个能量节点还必须报告
$T_{xx}$、$T_{\alpha\alpha}$、由同一映射导出的 $f$ 以及 $\overline T_{xx}$；不稳定映射没有有界相位椭圆，
必须明确报告该系数未定义，不能伪造数值。若该族保留多个可行解，仅在
**镜理论内部**按以下顺序选择代表解：最小化相位平均横向时间像差
$|\overline T_{xx}|$，最大化全能量窗的最小稳定裕量，最小化镜模型峰值场，最后最小化最大绝对镜电压。
这与理论中 $\overline T_{xx}\to0$ 的镜优化目标一致，且完全不借用 Stripe 的 $K$、作用量或电压。若在
冻结数值分辨率下仍无法区分，保留镜电压族 receipt，而不伪造唯一向量。

完整分析器加入两条 Stripe 的入口基线作用量后，也必须在 3900/4000/4100 V 三个节点分别计算局部
归一化周期斜率；两个“低/高节点周期减中心周期”的差值不能替代三条局部导数。三条导数使用同一组
固定硬件曲线、同一组 Stripe 电压和合同引用的能量微分步长。它们是全局 TE1/TE2 校准的输入诊断，
不应被误作 Stripe 三坐标求解的额外方程，也不要求当前 $L/W$ 或曲线系数等于论文样机的印刷值。

八个电压的**初始种子同样不是用户输入**。它应从当前冻结几何和理论按一条可追溯链自动派生：先以
Berdnikov 固定几何 L0/L1 独立生成 B--E 的解析种子/receipt，再由精确双 Stripe 作用量/响应消费该
receipt，生成 Stripe 种子及 $y=0$ 正镜转折目标态，最后由 source/focus--P1--负镜预反射--P2--
正侧Stripe--正镜转折的
硬边界棱镜式生成 P1/P2 种子；有限三维单位场射击只对下游 Stripe/P1/P2 理论种子作校正，绝不反向以 Stripe 理论拟合镜
电压。此分段只用于给各自的非线性求解器一个物理起点，不会把中间结果升格为最终解。加速器工作点
中心允许在 $4000\pm500\,\mathrm{eV}/q$ 内搜索；当前镜与 Stripe 的参考中心先取净加速增益
$4000\,\mathrm{eV}/q$，而不是把该值误作必须精确满足的最终加速器解。同一工作点内先以
$\pm100\,\mathrm{eV}/q$ 作为单粒子净增益设计包络，实际有限源区间必须逐粒子计算且允许非对称。
镜的三个轴向能量节点和 B--D 上界都由这些量派生：当前为 $3900/4000/4100\,\mathrm V$，
B--D 均不得高于 $3900\,\mathrm V$。E 同样不超过 $+10\,\mathrm{kV}$，但其闭合外端板电压必须
严格高于最高镜能量节点才能反射。入射前总动能为 $5\,\mathrm{eV}/q$，故当前加速器后总动能中心
另行记为 $4005\,\mathrm{eV}/q$；按用户指定，镜/Stripe 理想轴向能量仍只采用净增益 $4000\,\mathrm{eV}/q$。
不规定 B--E 的单调电压序。现存 `-40/+60 V` Stripe 与旧 P1/P2 电压仅服务既有几何审查 IOB，明确
禁止作为上述理论初值或 Candidate 工作点。

对当前冻结的 Stripe 形状，项目坐标 $y=0$ 必须注册到两条数学函数 $S_i(y)$ 的**自变量零点**，且
$S_i(0)$ 必须进入基线作用量和完整分析器周期。有限 CAD 曲线的机械起点或终点本身没有定义理论零点的
权威：曲线完全可以从 $y\ne0$ 开始绘制。当前装配中，函数零点恰好与一侧活动长 B-spline 边界共面，
但它不自动等于某个离子轨迹入口事件；后者必须由三维轨迹穿越实际边界来观察，不能反过来定义函数坐标。
四块 Stripe 的完整实体域是 $y=[-2,390]$ mm，而活动理论 B-spline 域是 $y=[0,390]$ mm；
$[-2,0]$ mm 是端部/修边机械段。因此可以把完整实体截面写成定义在 $[-2,390]$ mm 的分段函数，
但它不是同一个五次/一次活动理论函数向负 $y$ 的外推，理论响应 $S_i(y)-S_i(0)$ 和所有 $\eta$ 积分
仍从注册的函数零点开始。对 set-1 五次项进行原点平移判别：以 $y=0$ 为函数零点时，相对理论基系数方向
残差为 $6.35\times10^{-5}$；改取 $y=-2$ 时为 $9.45\times10^{-3}$，约大 149 倍。因此现有证据支持
“392 mm 实体、390 mm 活动函数”，不支持把端部 trim 并入同一条五次/一次理论函数。该比较是坐标诊断，
不是数值求解的通过容差。

数值验证顺序固定为：先用单个中心离子检查 P1 后负镜预反射、P2 后穿越正侧 Stripe、首个正镜转折落在
$y=0$、无撞电极、每次双镜 $z$ 转折、Stripe 慢漂移转折、同侧正镜转折周期、裸镜关断 Stripe 后得到的 $T_0/W$、以及
Stripe 开启时的实际 $K$；这些都闭合后，才运行冻结的小束团并报告
透过率、overtone、TOF/FWHM 和分辨率。单粒子只验证拓扑和标称量，不能单独证明焦点或分辨率。

双 Stripe L0 已具备与求解器无关的两项基础算子：由 $(\psi,g)$ 到两独立响应贡献的解析
$2\times2$ 反演，以及使用 $\eta=1-u^2$ 的端点正则化 $\kappa(1)$ 积分。它们只接受显式
目标函数与归一化，尚未将现有 CAD 曲线或审查电压伪装成该目标函数；项目工作点仍等待同源的镜周期 receipt、
Stripe 入口、转折点和 $\psi/g$ 目标。
