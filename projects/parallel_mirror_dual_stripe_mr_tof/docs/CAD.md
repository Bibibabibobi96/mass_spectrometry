# 开放路径平行镜双条带 MR-TOF SolidWorks 实施说明

## 当前资产边界

2026-07-21 接收的 CAD 是用户自绘、未经项目门禁验证的原始设计种子。文件整体冻结在当前
`parallel_mirror_dual_stripe_mr_tof` artifact根的`mr_tof`身份迁入快照中，保留原文件名和同目录关系，
避免人为破坏SLDASM对SLDPRT的相对引用。`mr_tof`是迁移前证据身份；该快照及原始CAD文件名只读
保留，不接收新运行，也不作为后续脚本或人工修改的工作目录。

当前活动目标是一组名义平行的伸长等时镜和两套独立偏压、独立形状的漂移条带电极组。冻结快照中的
`ion foil 1/2/3`等零件名只说明原始作者命名，不能据此推断独立电势数量、面对面配对或活动拓扑。
若审计发现快照未实现目标拓扑，它仍只是可借用的机械设计种子，不得反向改写项目身份或baseline。

## 首次审计门禁

开始参数化或几何修改前，应使用仓库规定的 SolidWorks 2022 工具链完成：

- 识别顶层装配及全部子装配，并记录实际解析到的零件路径；
- 检查缺失引用、外部引用、抑制件、轻化件、配置、单位和重建/保存警告；
- 建立 MR-TOF 本体与离子源、注入/引出、真空、检测和标准件的部件清单；
- 明确仪器轴、反射轴、注入面、引出面、检测面和共享坐标系；
- 验证两面伸长镜名义平行，并量化残余收敛角、扭转和装配误差；
- 把两套漂移条带分别映射为稳定的`drift_stripe_set_1`和`drift_stripe_set_2`，记录每套面对面电极、
  独立电势、独立形状边界及其接地/绝缘关系；
- 识别中央接地走廊和棱镜，确认注入与返回双程的机械通道；
- 从冻结快照复制到独立候选run后再修改，并在manifest中关联源快照哈希。

首次审计完成前，不把任何装配或零件晋升到`formal/cad/`，也不从现有几何反向猜测正式baseline。
