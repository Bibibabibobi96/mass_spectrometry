`config/qualification/`退出。原始 JSON 保持在 Git 历史中；本页只保存继续影响工程决策的结论，
不得作为可执行 profile 或重新授权依据。

- D2 hybrid build-only 网格以 884,643 单元通过拓扑和资源门禁；后续 MUMPS/PARDISO 粒子或场筛查
  超过当时资源帽。CG-AMG 能完成同类场求解，但没有建立连续数值资格。
- C1→D2 非轴向细化的场变化明显，C1不能作为空间参考；D2→D3仅支持轴向离散工程稳定，总体空间
  收敛仍未建立。
- 继承边界 0.50/0.40/0.32 mm 序列均能完成，但 0.40→0.32 mm 的常规区和接口区变化仍无来源化
  容差接受；继续到 0.256 mm 会越过冻结的百万单元预算。
- 出口局部 0.25 mm 策略较 0.32 mm 全长参考减少 83,386 单元，并在相邻 0.25→0.20 mm 比较中
  显示局部尺寸轴工程稳定；这不等同完整空间收敛。
- 无加速混合网格 N=100 粒子三臂功能通过，但 80→160 RF 步的发散变化仍明显，时间收敛未建立。
- SIMION A/R/Z/I/T 与 H15 定向跟进表明横向离散最敏感；H15相对相邻臂满足当前家族工程阈值，
  但数值收敛状态仍为 `DEFERRED_NOT_WAIVED`。

收敛预登记、dispersion合同与工程预算。任何新商业求解必须创建新的 campaign/profile/预算，不能
恢复本页所概括的旧身份。
