# TOF 时间误差预算：查表与计算

TOF 精度应先绑定允许的功能变化，再选择数值设置。跨项目不采用统一的 1、10 或 100 ps 合格线。
飞行时间必须是质量标定使用的有效时间 `T=t_detector-t0`，不能把注入等待时间或仪器总时钟加入。
窄峰的时间域关系为 `R=T/(2W)`，其中 `W` 是时间 FWHM。它不要求峰为高斯；但不能把逐粒子最大
时间差或时间标准差直接代入 `W`。

固定同一个有效飞行时间 T，给定参考分辨率 `R0` 和允许的最低分辨率 `Rmin`，共同时间偏移另行预算：

```text
参考峰宽 W0 = T/(2 R0)
允许峰宽 Wlim = T/(2 Rmin)
剩余峰宽裕量 = Wlim - W0
```

`Rmin>R0` 表示参考本身尚未达标，没有可分配的新增展宽预算；相等时预算为零。
若输入的是允许分辨率下降比例 `L`，则 `Rmin=R0(1-L)`，不能同时声称结果仍须大于同一个 `R0`。
R0 应注明来源及已包含的源、场、探测器等展宽；若还有未计入的误差，须先给它们留出份额，
不能把全部剩余裕量分给数值求解。计算器给出的是声明参考之外的新增误差上限。
以下误差规划以参考峰近似高斯为条件，定义 `k=sqrt(8 ln 2)`、`sigma0=W0/k`、`h=(R0-Rmin)/Rmin`：

| 新增时间误差模型 | 允许的误差标准差 |
|---|---|
| 独立、零均值、高斯误差 | `sigma_error <= sigma0 sqrt(h(2+h))` |
| 与原时间偏差完全同向的高斯展宽 | `sigma_error <= sigma0 h` |

二者来自 `Var(t+e)=Var(t)+Var(e)+2 Cov(t,e)`。不能在没有独立性证据时采用平方和，也不能借负相关
或误差抵消制造预算。这些是标准差预算，不是逐粒最大误差、积分步长或求解器相对容差。
非高斯、多峰、尾部或截断峰必须用配对粒子重新计算项目规定的直接 FWHM、峰形和事件集合；上表
不保证 canonical KDE-FWHM 的变化界。

所有粒子相同的时间偏移不展宽峰，但可能改变固定外标质量。若允许相对质量偏差为 `p`（例如
1 ppm 对应 `p=1e-6`），由 `m proportional to T^2` 得到双向保守偏移限：

```text
abs(common_time_bias) <= T p/(sqrt(1+p)+1)
```

该稳定表达式避免两个相近数相减。若质量用当前样本平均 TOF 自归一化，共同偏移可能被隐藏，仍须
单列绝对时间偏移；质量准确度和分辨率是不同预算。

唯一计算入口是 [`tof_error_budget.py`](../common/analysis/tof_error_budget.py)，使用标准库，不启动求解器：

```powershell
python -m common.analysis.tof_error_budget --flight-time-us 100 --reference-resolution 100000 --max-resolution-loss-pct 1 --mass-bias-ppm 1 --format markdown
```

默认输出供脚本读取的 JSON；`--format markdown` 输出供人查阅的表格，两种输出消费同一份计算结果。
也可用 `--minimum-resolution` 显式给出 `Rmin`，与下降百分比互斥。Python 调用
`calculate_tof_error_budget(T_seconds, R0, minimum_resolution=Rmin, mass_bias_limit_ppm=...)` 返回 SI 单位
JSON 数据；目标未达时新增噪声预算为 `null`。输出始终 `qualification=false`：这是误差分配，不是
模型验收，也不自动选择 COMSOL 的 `rtol`、最大步长或输出间隔。

日常使用时，先选相同参考 R0 的行；若允许下降仍为 1%，将该行所有时间列乘以
`实际 T/(100 us)`。例如 T=71.3528 us 时乘以 0.713528。若最低分辨率或允许下降比例不同，
直接调用计算器重算；不能只按飞行时间缩放原表。

RF 部件没有 TOF 质量分辨率目标时，不套用本表。若下游已经给出允许 RF 相位偏差 `dphi`（度），
相同 RF 时钟下的时间偏差限为 `dt=dphi/(360 f)`；它仍不是积分步长。传输率、孔径裕量、位置、
速度、能量、损失分类和碰撞统计须使用各自的功能预算。

达到结果误差预算后停止无收益加严。实际采用的数值配置应是经过独立收敛、重复和功能指标验证后
成本最低的一档；若尚无功能预算，先报告误差与成本曲线及适用边界，不把任意 ps 整数变成工程要求。
