# 外部参考资料

返回[文档任务目录](../README.md)。本入口统一定位外部原始资料；仓库自产理论、实现与验证结论仍由
所属项目或公共文档维护。资料不决定项目划分，不作为默认物理输入，也不自动证明仓库已有某项能力。

| 资料类型 | 唯一索引 | 本地文件位置 |
|---|---|---|
| 学术书籍与论文 | [书目与定向阅读](literature/README.md) | `literature/` |
| 供应商软件手册 | [版本与接口定位](software/README.md) | `software/` |

索引记录来源、版次、定位与必要文件身份；PDF仅本地保存，公开Git与干净checkout不携带全文。
缺失时按对应索引取得适用版本，不依赖某台机器的用户路径。大型资料先定位问题，再读取相关页。
具体保留、引用和迁移规则见[生命周期](../LIFECYCLE.md#外部参考资料)。
