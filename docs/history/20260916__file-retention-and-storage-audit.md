## 发现与修复

| 问题 | 处理与效果 |
|---|---|

| 删除先发生、收据后生成 | 先冻结逐文件SHA和pending，再处置并完成收据；部分失败保留可审计状态 |
| 退休入口信任替代manifest的声明 | 验证两端完整记录及config/summary/输入绑定，执行前复核 |
| 公共水位多处默认值含义不一 | 默认值收敛到现有JSON策略；artifact上限与整盘最小余量分开，当前均为500GiB |

| 公共COMSOL测试写入无归属模型目录 | 16入口显式接收同一受管项目run/scratch上下文，禁止覆盖终态run |

没有新增数据库、调度器或清理服务。资源许可与文件容量保护职责分开：轻重任务可并行，
运行器仍须精确保护其消费对象。项目现有显式500GiB参数仍可作为覆盖值，未在活动MR代码中强改。

## 保留决策与未恢复的历史问题

| 范围 | 本轮决策/原因 | 后续退出条件 |
|---|---|---|
| 活动MR运行、失败/中断输入与当前cache代 | 保留；另一任务持续消费，两份有效TTL保护保持 | 所属任务闭合、确认替代与精确消费关系 |
| OA campaign缓存 | 保留；现有有效租约与冻结输入需求 | campaign结束或明确解除保护后再验证可重建性 |
| hex/oct四组旧schema PA basis，约15.17GiB | 保留；其中一组来源run缺失，不能声称可重建 | 补齐来源或确认替代，并逐项授权处置 |
| 五个旧科学Temp目录，约32.24GiB | 保留；可能含唯一输入/恢复材料 | 确认来源与替代，不按前缀/年龄强删 |
| 当前MR Temp副本、basis比较、C盘恢复PA | 保留；运行消费或故障证据尚未闭合 | 消费者结束且恢复/替代身份通过 |
| OA paper1_stage_evidence、集成两组resolution_matrix | 保留；当前或冻结文档引用原位置 | 用可验证迁移映射处理原引用；本轮未改写历史身份 |
| 双锥旧scratch名称 | 保留真实原型证据；名称不合当前合同 | 确认内容与消费者后保真迁移，不能只改名影响嵌入路径 |

上述是本次审计的处置理由，不是新增永久保留白名单，也不豁免结构门禁。
逐项目检查发现旧八极杆run缺summary、MR某JSON解析失败及若干旧布局问题，记录在
`common/capacity_disposal_receipts/project-layout-audit-20260916.json`；加速器缺失的导航文件已补齐。
旧父级prepulse publication在本次清理前已有三份输入丢失和代码身份漂移；
本次只验证成功的compact恢复结果，不声称父链已经修复。不得伪造summary或重写manifest以制造PASS。

完整TRACE的failed-recovery豁免仍需所属恢复流程绑定完成/退出条件，不能仅靠TTL删除原始失败证据。
Paper阶段发布器允许任意destination也是尚存入口边界；本轮未修改暂停中的OA科学发布流程。

源码卫生已通过；L1/L2结果与CLOC完整语言分类表随本次交接记录，不用源码测试PASS代替本机旧artifact完整性。

提供输出上下文，旧无参调用会报错，这是关闭无归属输出的有意接口变更。新增测试和审计代码不属于减行重构；
目标是避免误删与防止再次失序，不能以行数下降替代正确性。
