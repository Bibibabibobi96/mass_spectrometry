# 多极杆工程推进18项重分析

## 目的与证据边界

本记录把四、六、八极杆现有无加速N=100结果按统一工程口径重新汇总，供人直接复核。它承接
[`20260731__no-acceleration-multipole-discretization-followup.md`](20260731__no-acceleration-multipole-discretization-followup.md)
的数值敏感性结论，但不改变原结论：数值收敛仍未建立，也未被豁免。

本次没有启动COMSOL或SIMION求解，只读取21个已验证的canonical run，形成每个家族六项比较：

- SIMION：`A→R`横向加密、`A→Z`轴向加密、`A→I`各向同性加密、`I→T`时间加密；
- COMSOL：当前混合网格的`C160→C320`时间加密；
- 跨求解器：当前最佳可用的`COMSOL C320→SIMION T`描述性配对。

工程判据来自
[`engineering_progression_acceptance.json`](../../common/multipole/engineering_progression_acceptance.json)：
束流质心位置差和质心化空间展宽差分别不超过`0.2 mm`，平均束流方向差和质心化角展宽差分别
不超过`1°`。平均能量差及质心化能量展宽差尚无获批的下游阈值，因此任何一行都不能签发工程推进
`PASS`。

## 汇总结论

18项比较的四个已批准工程量全部通过。全矩阵最大值为：

- 束流质心位置差：`0.056798 mm`；
- 质心化空间展宽差：`0.118671 mm`；
- 平均束流方向差：`0.669877°`；
- 质心化角展宽差：`0.580952°`。

待定能量证据的全矩阵最大值为平均能量差`0.019592 eV`、质心化能量展宽差`0.024395 eV`。
这些数值可供oa-TOF下游容差制定使用，但不能反向充当已经批准的阈值。

SIMION时间臂在当前固定离散下变化最小；SIMION空间敏感性主要来自横向加密。当前最大空间、角度和
能量差均出现在六极杆跨求解器配对，但仍低于已批准的空间/角度工程界限。跨求解器行只描述当前
最佳可用配对，不证明COMSOL与SIMION等价，也不能据此判断哪个求解器更准确。

## 处置

本矩阵保持一次性历史审计，不加入每次提交或每次实验的常规门禁。常规单次实验继续生成出口状态图；
机械几何、粒子源、handoff接口、场/网格策略、积分器、固定分箱合同、求解器大版本或资格里程碑变化时，
再决定是否重跑完整矩阵。下一项工程决策是由oa-TOF下游需求批准平均能量差和能量展宽差阈值。
